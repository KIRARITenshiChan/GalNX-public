## 结论
1. hacBrewPack v3.05 对 2.86 GiB 真实 payload 出包成功：NSP 2,884,106,456 B，仅比输入 romfs 大 5,920,884 B（约 0.2% 开销）；Program NCA 2.88 GB 正常，无 >2 GiB section 上限问题。
2. 无内存瓶颈：峰值 111 MiB，与 romfs 体积无关（romfs_build 流式拷贝 + IVFC 逐层落临时文件）。
3. 磁盘峰值约 3 倍 romfs（2860 档 work 峰值 7.407 GB；A1 阶段叠加约 8.4 GB）。
4. 吞吐约 36-37 MB/s（2.878 GiB / 230 s）；3400 档 3.57 GB / 95.2 s（约 37.5 MB/s，注意该档文件为不可压缩 hash 块但读取缓存不同）。
5. 200/1024/2860/3400 四档 NSP 均 < FAT32 4 GiB；3.4 GiB 档余量约 722 MB，2.86 GiB 档余量约 1.39 GB。
6. 2860 两个 run 尺寸完全相同但 sha256 不同（RSA-PSS 随机盐，非确定性）；3400 与 2860 的 Program NCA 内 romfs 内容均由 nstool --part1 抽回并 round-trip 校验通过（见 P1d-romfs-roundtrip.txt）。
