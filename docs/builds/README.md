## 构建约定

1. 构建根目录一律放**无空格**路径（如 `E:/galnx-build/<id>`）；源工程可在含空格路径，构建产物与中间目录不行。
2. devkitPro 调用：`env MSYSTEM=MSYS CHERE_INVOKING=1 /d/devkitPro/msys2/usr/bin/bash.exe -lc '<cmd>'`。
3. 记录 `pacman -Q` 相关包版本、CMake 版本、完整命令、退出码、产物大小与 SHA-256。
4. 不提交任何商业游戏数据或密钥；测试资源只用可合法再分发的 fixtures（第三方资源登记见 `docs/third_party/README.md`）。
