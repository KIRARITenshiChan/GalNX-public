## 2 每个包在真机上确认了什么（口径）

### 2.1 共通项（四个 rfvp 包）

| 项目 | 确认方式 |
| --- | --- |
| 安装与启动 | MTP 拷入 NSP → 自制系统安装 → 从 HOME 图标启动（0.1.0 起图标为用户提供的 256×256 封面或 OP 抽帧） |
| 手柄映射 | A=确认/Enter、B=返回、方向键=方向、右摇杆=光标、ZR/ZL=左/右键按住、R=Ctrl 快进、+=存档、-=退出、X=自动、Y=读档（与 `docs/pilot/` 的映射表一致） |
| 电影 | 剧情触发的 OP 能播放（H.264 走 NVDEC + NV12 零拷贝；无 NVDEC 场景才回退软解） |
| 退出 | 菜单/热键退出不崩溃、设置与存档落盘 |

## 4 复验步骤（发布回归用）

1. 用 `scripts/build_nsp_game.sh` 或 `galnx package nsp build` 重建目标包，记录 sha256。
2. `galnx package nsp verify`（TitleID/ProgID、NCA、romfs 摘要）必须 `ok=true`，唯一允许的 warn 是「未签名 homebrew」。
3. Citron 首启冒烟（`scripts/citron_run.sh --game <nsp> --no-stage --expect-title <TITLE>`）只作**入口检查**，不等于真机验证。
4. 真机安装后按 2.1/2.2 逐项过一遍，把结果补进 `docs/engines/verification-matrix.md` 与本文 §1。
5. 若只是换引擎/图标而 romfs 未变（如 P45），回归可以只做启动 + OP + 输入 + 退出四项，并在证据里注明 romfs 摘要未变。
